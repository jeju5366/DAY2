## 🎯 프로젝트 소개

- 🌟 **한 줄 요약**: 제주도 괜찮은 카페 알아보는 기능
- ☕ 제주에는 카페가 정말 많아서 어디를 가야 할지 고르기 어려워요
- 🤖 에이전트가 사용자의 취향을 먼저 물어보고
- 🏝️ 취향에 맞는 인기 카페를 골라서
- 📝 카페마다 어떤 특징이 있는지 알려줘요
- 😊 여행 준비 시간을 줄이고, 실패 없는 카페 선택을 돕는 게 목표예요

### 🌈 이 에이전트의 장점

- ⏱️ 검색 시간을 아껴줘요
- 🎨 취향에 맞춘 개인화 추천을 해줘요
- 🧾 카페 특징을 한눈에 비교할 수 있어요
- 🤝 질문을 통해 사용자의 목적을 이해해요
- 💬 대화하듯 편하게 쓸 수 있어요

## 🙋 대상 사용자

| 항목 | 내용 |
|------|------|
| 👤 사용자 | **고지현** |
| 🧳 상황 | 제주도 여행(또는 방문) 중 카페를 찾고 싶음 |
| 🎯 니즈 | 취향에 맞는 인기 카페를 빠르게 알고 싶음 |
| 📱 사용 방식 | 질문에 답하면 추천 결과를 받음 |

### 🧑‍💻 사용자 페르소나

- 🌿 분위기 좋은 공간을 좋아할 수 있어요
- 🍰 디저트와 음료 맛을 중시할 수도 있어요
- 📸 사진 찍기 좋은 곳을 찾을 수도 있어요
- 💻 작업이나 휴식이 목적일 수도 있어요
- 👭 친구, 가족, 연인과 함께 갈 수도 있어요

## 💬 사용자 질문 예시

에이전트는 아래와 같은 질문으로 사용자의 취향을 파악해요 👇

### 1️⃣ 카페에서 중요하게 생각하는 요소는?

- 🛋️ 분위기, 인테리어
- 🥤 음료 맛
- 🍩 디저트 종류
- 🌅 뷰, 전망
- 🚗 주차, 접근성
- 💸 가격

### 2️⃣ 카페 분위기 vs 음료 및 디저트 퀄리티

- 🎀 분위기가 더 중요한가요?
- 🍵 맛과 퀄리티가 더 중요한가요?
- ⚖️ 둘 다 균형이 맞아야 하나요?
- 🔁 상황에 따라 달라지나요?

### 3️⃣ 평소 카페 이용 목적은?

- 😌 휴식, 힐링
- 💬 수다, 모임
- 📚 공부, 작업
- 📷 사진, 인증샷
- 🎁 디저트 먹으러 가기
- 🌊 여행 중 잠깐 쉬어가기

- 🐶 반려동물 동반 가능 여부
- 🅿️ 주차 가능 여부
- 👶 키즈 친화 여부
- 📸 포토 스팟 유무
- 🔌 콘센트, 와이파이 등 작업 환경

## 🧭 에이전트 동작 흐름

1. 👋 사용자에게 인사하고 목적을 물어봐요
2. ❓ 취향 질문 3가지를 순서대로 해요
3. 🧠 답변을 바탕으로 사용자 취향을 정리해요
4. 🔍 제주도 인기 카페 목록을 찾아요
5. 🧮 취향과 맞는 카페를 골라요
6. 🧾 카페별 특징을 정리해요
7. 🎁 추천 결과를 보기 좋게 보여줘요
8. 🔄 마음에 안 들면 조건을 바꿔 다시 추천해요

### 🔀 흐름 요약

```text
👤 사용자 → ❓ 취향 질문 → 🧠 취향 분석
        → 🔍 카페 검색 → ✨ 특징 정리 → 🎁 추천 결과
```

## 🗂️ 추천 결과 형식

추천은 아래처럼 보여줄 예정이에요 💌

### ☕ 카페 이름 예시

- 📍 **위치**: 제주시 / 서귀포시 등
- ⭐ **인기 포인트**: 리뷰 많고 평점 높음
- 🎨 **분위기**: 감성적이고 아늑함
- 🍰 **추천 메뉴**: 시그니처 음료, 디저트
- 🚗 **편의 정보**: 주차, 반려동물, 좌석 등
- 💖 **추천 이유**: 사용자의 취향과 맞는 이유

### 🧩 비교표 예시

| 카페 | 📍 위치 | 🎨 분위기 | 🍰 맛 | 💖 추천 대상 |
|------|---------|-----------|-------|--------------|
| 카페 A | 제주시 | 🌿 아늑함 | ⭐⭐⭐⭐ | 휴식 목적 |
| 카페 B | 서귀포시 | 🌊 오션뷰 | ⭐⭐⭐⭐⭐ | 사진, 여행 |
| 카페 C | 애월 | 🏡 감성 | ⭐⭐⭐⭐ | 수다, 모임 |

> 📌 위 표는 형식을 보여주는 예시이고, 실제 카페 정보는 에이전트가 찾아서 채워요
